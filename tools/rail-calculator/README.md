# 마그네틱 레일 계산기 (Rail Calculator)

설치 길이·형상을 입력하면 필요한 마그네틱 레일 조합, 절단 계획, 부속품,
권장 안정기(48V)까지 자동으로 계산해 주는 툴입니다.

- **파일**: `index.html` (단독 실행 가능, 별도 서버 불필요)
- **담당자**: KANT
- **기능 요약**
  - 제품 선택: 5mm / 15mm / 17mm / 28mm Magnetic
  - 설치 위치: 천장-천장 / 천장-벽면 (연결부속 여유 자동 반영)
  - 설치 형상: 일(ㅡ)자 / ㄱ자 / ㅁ자
  - 레일 구매 목록 · 재단(절단) 계획 · 부속품 목록 자동 산출
  - 설치 도면(SVG) 미리보기
  - 결과 이미지 저장(PNG) · 텍스트 내보내기

> 이미지 저장 기능은 외부 라이브러리(snapDOM)를 CDN에서 불러옵니다.
> 인터넷이 없는 환경에서는 이미지 저장만 동작하지 않고, 계산 기능은 정상 작동합니다.
