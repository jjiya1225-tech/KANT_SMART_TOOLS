# 인보이스 변환기

인보이스 엑셀(.xlsx)을 업로드하면, 셀에 박힌 제품 이미지까지 함께 읽어
환율 적용가·업체가·온라인가를 자동 계산한 **제품 목록 엑셀**로 변환해 주는 툴입니다.

- **파일**: `index.html` (단독 실행 가능)
- **담당자**: KANT
- **기능 요약**
  - .xlsx 업로드 (드래그 앤 드롭 지원), 'invoice' 시트 자동 우선 선택
  - 셀 이미지 추출(제품 사진) → 결과 엑셀에 이미지 포함 저장
  - 통화(CNY/USD)·환율·반올림 단위·업체가/온라인가 배수 설정
  - 헤더 행·데이터 시작 행 자동 감지, 열 매핑 수동 조정 가능
  - 변환 결과 미리보기(표+통계) 후 엑셀 다운로드

> **인터넷 필요:** 엑셀 파싱·이미지 포함 저장을 위해 외부 라이브러리
> (JSZip, SheetJS, ExcelJS)를 CDN에서 불러옵니다. 오프라인에서는
> 이미지 포함 저장이 안 되고, 이미지 없는 엑셀로 대체 저장됩니다.
