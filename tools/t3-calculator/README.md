# T3 설치 계산기

설치 길이·형상을 입력하면 필요한 T3 조명 조합(추천 + 대안)을 자동으로
계산해 주는 툴입니다. 남는 여유(margin)를 최소화하는 조합을 우선 추천합니다.

- **파일**: `index.html` (단독 실행 가능, 별도 서버 불필요)
- **담당자**: KANT
- **기능 요약**
  - 설치 형상: 일(ㅡ)자 / ㄱ자 / ㅁ자
  - 전원 입력선(20mm) 여유 자동 반영
  - 연결선 수량 자동 안내 (일자 1 / ㄱ자 2 / ㅁ자 4)
  - 면(변)별 상세 조합을 추천 1개 + 대안 2개로 제시
  - 사용 규격: 1500 / 1200 / 1000 / 900 / 600 / 400 / 300mm

> 화면 폰트로 Noto Sans KR을 구글 폰트 CDN에서 불러옵니다.
> 인터넷이 없으면 기본 폰트로 표시되며, 계산 기능은 정상 작동합니다.
