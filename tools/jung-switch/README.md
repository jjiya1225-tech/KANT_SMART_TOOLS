# JUNG 융스위치 구성기 (내부용)

색상·구 수·기능 모듈을 조합하면 실사 미리보기와 함께 단가를 자동
계산해 주는 툴입니다. 상단 토글로 온라인가·업체가를 즉시 전환합니다.

- **파일**: `jung-internal.html` (단독 실행 가능, 별도 서버 불필요)
- **담당자**: KANT
- **기능 요약**
  - 단가 토글: 온라인가 ⇄ 업체가 (우측 상단, 누르면 전 항목 실시간 재계산)
  - 소재·색상: 듀로/무광/메탈/브라스 · 12색상, 실사 합성 미리보기
  - 프레임: 1~5구 (세로 고정, 구 수 늘면 가로로만 확장)
  - 기능 모듈: 스위치·디머·콘센트·USB·통신/AV·기타 위치별 배치
  - 매립박스: 선택(옵션), 방우형 등 실사 반영
  - 목록: 공간명 자동 넘버링(거실→거실 2) · 담은 항목 수정/삭제
  - 견적: 공급가·부가세·합계 실시간 + 견적요청서 PDF + 구성코드/카카오 전송

> 실사 이미지·단가가 파일에 내장되어 인터넷 없이도 조합·계산이 작동합니다.
> ⚠️ 업체가가 노출되는 내부 전용 파일 — 고객용 공개 페이지에는 올리지 마세요.
