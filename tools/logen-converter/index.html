로젠 변환기

엑셀 파일을 끌어다 놓으면 상대 시스템 양식으로 바꿔줍니다. 설치할 것도, 업로드되는 것도 없습니다 — 변환은 전부 이 브라우저 안에서만 일어납니다.

이카운트 → 로젠

로젠 업로드 파일 만들기

이카운트에서 받은 Excel을 넣으면 로젠 복수건 등록용 D타입 8열 파일이 나옵니다. 배송처리와 판매조회 두 양식 다 됩니다 — 어느 쪽인지는 알아서 가려냅니다.

    로젠 → 이카운트

    송장 등록 파일 만들기

    로젠 송장 출력 파일을 넣으면 이카운트 웹자료올리기에 붙여넣을 내용이 나옵니다. ①을 이 브라우저에서 했다면 로젠 파일 하나면 됩니다. 아니면 배송처리 Excel을 같이 넣어주세요.

      쓰는 순서

      1. 이카운트 배송처리 화면에서 Excel 버튼으로 파일을 받습니다.
      2. 왼쪽 칸에 넣고 로젠 업로드 파일을 받습니다. 주문이 묶음 단위로 접혀 상자 1개 = 1행이 됩니다.
      3. 로젠 프로그램 주문등록 › 복수건 등록에 그 파일을 올리고 송장을 출력합니다.
      4. 로젠 출력 파일과 1번의 배송처리 Excel을 오른쪽 칸에 함께 넣습니다.
      5. 클립보드에 복사를 누르고, 이카운트 배송처리 › 웹자료올리기 첫 칸에 붙여넣은 뒤 저장(F8).
      로젠에 접수할 때 A열(주문번호)이 그대로 살아 있어야 합니다. 거기 담긴 묶음주문번호가 송장 출력 파일로 돌아와야 어느 송장이 어느 주문인지 맞출 수 있습니다. 로젠 엑셀타입설정에서 A열이 주문번호로 잡혀 있는지 확인하세요.

      대신택배 건은 이 도구를 쓰지 않습니다. 수기 접수 후 이카운트 배송처리에 DAESIN 코드로 직접 입력하세요.
      변환은 브라우저 안에서만 실행됩니다 · 고객 정보가 서버로 전송되지 않습니다
