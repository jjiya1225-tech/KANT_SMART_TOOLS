# 로젠 변환기

이카운트와 로젠 사이에 오가는 엑셀을 서로의 양식으로 바꿔 주는 툴입니다.
출고할 때 같은 정보를 두 시스템에 손으로 옮겨 적던 작업을 없앱니다.

- **파일**: `index.html` (단독 실행 가능)
- **담당자**: KANT
- **기능 요약**
  - **왼쪽 · 이카운트 → 로젠**
    배송처리 화면의 `Excel` 파일을 넣으면 로젠 **복수건 등록**용 D타입 8열 엑셀 생성
    묶음주문번호 단위로 접어 **상자 1개 = 1행**, 여러 품목은 물품명을 합침
  - **오른쪽 · 로젠 → 이카운트**
    로젠 송장 출력 파일 + 배송처리 Excel을 함께 넣으면
    이카운트 **웹자료올리기**에 붙여넣을 내용 생성 (클립보드 복사 / 파일 저장)
    상자 단위 송장을 줄 단위로 펼쳐 **합포장은 모든 줄에 같은 송장번호**
  - 두 파일은 **순서를 가리지 않습니다** (열 이름으로 자동 판별)
  - 매칭 안 된 상자, 300줄 초과 등은 화면에 요약으로 알려줍니다

> **인터넷 불필요:** 외부 라이브러리를 쓰지 않습니다. 엑셀 읽기·쓰기를
> 브라우저 기본 기능만으로 처리하므로 **고객 정보가 서버로 전송되지 않습니다.**
> 글꼴만 온라인에서 불러오며, 없어도 동작에는 지장이 없습니다.

## 전제조건

로젠에 접수할 때 **A열(주문번호)에 담긴 묶음주문번호가 송장 출력 파일로 돌아와야** 합니다.
로젠 `엑셀타입설정`에서 A열이 `주문번호`로 잡혀 있는지 확인하세요.
비어서 돌아오면 오른쪽 패널이 매칭할 열쇠가 없습니다.

대신택배 건은 이 툴을 쓰지 않습니다. 수기 접수 후 이카운트 배송처리에
`DAESIN` 코드로 직접 입력하세요. (로젠은 `KGB`)
