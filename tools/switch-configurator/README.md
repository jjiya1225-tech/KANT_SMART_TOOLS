# 스위치 구성기 (6개 브랜드)

고객이 브랜드 → 색상 → 구 수 → 칸별 기능 → 시공 부속을 고르면 실물과 같은 그림이
실시간으로 그려지고 합계 금액이 나오는 툴입니다. 구성한 내역은 브랜드가 달라도
하나의 견적 요청서로 묶여 이미지로 저장·전송됩니다.

- **파일**: `index.html` (단독 실행 가능, 인터넷·서버 불필요)
- **담당자**: KANT
- **가격**: **소비자가(온라인가)만** 들어 있습니다. 업체가·입고가는 포함돼 있지 않습니다.

## 브랜드 6종

| | 브랜드 | 구성 |
|---|---|---|
| 1 | JUNG LS990 | 12색 · 1~5구 |
| 2 | RHYTHMICA (리드미카) | 15색 · 1~8구 |
| 3 | DIA (서울산전 다이아) | 2색 · 1~5장 |
| 4 | GALION UP (르그랑 갈리온) | 4색 · 1~5개용 |
| 5 | ARTEOR (르그랑 아테오) | 6색 · 1~5장 |
| 6 | AFFELA (르그랑 아펠라) | 5색 · 1~5장 |

홈 화면은 위 3개 · 아래 3개로 배치되며, 모바일에서도 3열을 유지합니다.

## 기능 요약

- 모든 스위치를 **벡터 SVG 로 실시간 렌더링** (사진 파일 없음)
- 브랜드 공통 장바구니 — 여러 브랜드를 한 견적서에 담기
- 견적 요청서 이미지 저장 + 구성 코드 + 카카오톡 채널 전송
- 시공 부속(매입박스·지지대·MDF 프레임·스틸 박스) 선택
- **외부 리소스 0개** — 이미지·폰트·CDN 을 하나도 쓰지 않습니다

## 아임웹에 넣을 때

같은 폴더의 `imweb-inline.html` 을 씁니다. 아임웹 **코드 섹션에 그대로 붙여넣는**
버전으로, iframe 없이 동작하도록 CSS 가 `#kantsw` 아래로 스코프돼 있습니다.
(`index.html` 은 단독 실행·iframe 삽입용입니다.)

## 수정하려면

이 `index.html` 을 직접 고치지 마세요. `part1~5.html` 조각을 이어 붙인 결과물입니다.

```
~/Desktop/Claude/Switch/       ← 작업 폴더 (소스·빌드·검증)
  소스/part1~5.html            ← 여기서 수정
  ./build.sh                   ← 빌드 → index.html + imweb-inline.html
```

규칙과 함정은 작업 폴더의 `CLAUDE.md`, 전체 배경은
`>_인수인계/인수인계_스위치_구성기.md` 를 보세요.
